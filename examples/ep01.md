# 硅谷早茶 · 第 1 期

> 一个示例公众号连载栏目，演示 LanYin 如何把 `##` 章节标题变成可订阅有声资产的章节标记。

## 第一章 为什么要锁栏目级音色

通用 TTS 每期重新合成、音色跨期漂移；公众号作者想做小宇宙/喜马拉雅有声臂，
第 11 期的声音已经对不上第 3 期。栏目级音色锁把同一把 voice_id 锁进
`.lanyin/voice-lock.json`，让同一栏目跨 10 期盲测一致。

## 第二章 MiniMax H3 是底座，LanYin 是工作流

MiniMax H3 是 omni-modal 立体声生成底座，但缺公众号连载→小宇宙/喜马拉雅有声
系列的工作流：没有栏目级音色锁、没有章节切分、没有平台合规导出。LanYin
给底座接上这三层，把通用底座变成可订阅的中文连载有声资产。

## 第三章 一条命令出可订阅系列

```bash
lanyin voice lock --sample ./voice.mp3 --name "作者签名音色"
lanyin build ./ep01.md
lanyin export rss --platform xiaoyuzhou
```

锁一次音色，每期复用同一 voice_id；`##` 标题自动变章节；导出即平台合规。
